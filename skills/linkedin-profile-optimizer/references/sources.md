| ID | Fuente | Qué respalda | Límite |

| L6 | [Let recruiters know you’re Open to Work](https://www.linkedin.com/help/linkedin/answer/a507508) | Preferencias, visibilidad y límites de privacidad | No garantiza contactos ni privacidad absoluta |

| L8 | [Request a recommendation](https://www.linkedin.com/help/linkedin/answer/a546682) | Relación, cargo, mensaje e idioma principal en solicitudes | No demuestra ranking por cantidad de testimonios |

**Inconsistencia observada:** L1 contiene una formulación que limita el perfil a un idioma; L5 documenta expresamente versiones adicionales. Para crear/editar versiones usar L5 y la interfaz vigente. No deducir de estas páginas cómo combina el motor de búsqueda todas las versiones.

Las páginas L3 y L4 consultadas no acreditan máximos permanentes de caracteres. Los valores del helper son objetivos editoriales configurables de esta skill. Verificar los límites en la interfaz antes de publicar.

## En cada auditoría

1. Confirmar fecha actual y objetivo profesional; no reutilizar como “actual” la fecha de este documento.
2. Leer fuentes pertinentes. Preferir ayuda oficial para funcionalidades, documentación del proveedor para tecnologías y anuncios del empleador para requisitos laborales.
3. Registrar URL, título, fecha publicada cuando exista, fecha de consulta y afirmación exacta respaldada. No citar únicamente un snippet si la página accesible lo contradice.
4. Distinguir hechos de plataforma, evidencia del candidato, patrones de una muestra e inferencias editoriales.
5. Si una página no abre, declarar la limitación y recurrir a otra fuente primaria o al material aportado; no afirmar lectura completa.
6. Al actualizar la skill, revisar cambios, referencias y ejemplos sintéticos. No incorporar datos de perfiles reales.
